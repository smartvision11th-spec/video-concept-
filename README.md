# IRON FITNESS — Architectural Strength Sanctuary

A brutalist, architectural luxury fitness and athletic performance web application generated from your Google Stitch design specifications.

## Design System Tokens
- **Primary Color:** `#eebe87` (Warm Antique Bronze / Gold)
- **Primary Container:** `#b58a58`
- **Surface / Background:** `#0e0e0e` / `#131313` / `#1c1b1b` / `#201f1f`
- **Typography:**

  - Body, Copy & Labels: **Manrope** (Light, Regular, Medium, Semibold)
- **Icons:** Material Symbols & Lucide

## Quick Start

### 1. Run Development Server
```bash
npm run dev
```
Runs at `http://localhost:3000` with hot module reloading.

### 2. Standalone Instant Preview
Double-click `preview.html` to open in any web browser without any local server.
